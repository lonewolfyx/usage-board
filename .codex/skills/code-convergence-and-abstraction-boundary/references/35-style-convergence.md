# Style Convergence

## Applicability

Use this reference for repeated Tailwind classes, repeated variants, repeated dark mode, repeated responsive layout, and repeated base component styles.

## Best Practices

1. Converge stable design-semantic values into design tokens.
2. Converge runtime-switchable style values into CSS variables.
3. Converge repeated class combinations into class helpers.
4. Converge size, variant, and color rules into a variant system.
5. Converge foundational control styles into base components.
6. Converge atomic style reuse into Tailwind utilities when appropriate.

## Do Not

1. Do not keep multiple class combinations for the same UI semantic.
2. Do not repeatedly maintain base UI styles inside domain components.
3. Do not scatter dark-mode or responsive-layout logic.
4. Do not create one-off helpers for class combinations that have no reuse value.
